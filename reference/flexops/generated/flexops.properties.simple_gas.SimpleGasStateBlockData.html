SimpleGasStateBlockData¶

class flexops.properties.simple_gas.SimpleGasStateBlockData(*args, **kwargs)¶

State block carrying flow, pressure, and temperature.

State variables are indexed over time directly: the owning unit passes the time_index Set via build_state_block(time_index=...) and gets a single scalar state block whose variables span the horizon. Extensive, per-phase quantities lead with time then phase (flow_vol_phase[t, phase]); intensive stream properties drop the phase index (pressure[t], temperature[t], assumed equal across phases).

build() → None¶

Create the three time-indexed gas state variables.

define_display_vars() → dict¶

Return the display-variable dict for reporting.

define_state_vars() → dict¶

Return the state-variable dict (flow plus any enabled extras).
