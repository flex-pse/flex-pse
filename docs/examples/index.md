# Examples

Worked, solved examples built on the public flex-pse API live in the
companion repository
[flex-pse-examples](https://github.com/flex-pse/flex-pse-examples). You can
browse them as an interactive site at
[flex-pse.github.io/flex-pse-examples](https://flex-pse.github.io/flex-pse-examples/).
Each example opens directly in a browser. You don't need to install
anything or set up a solver. Every example shows a real flowsheet, a solved
schedule, and the tariff or dispatch signal that shaped it.

That site is a separate project with its own version history, so people can
add examples and update them without waiting on this repository's release
cycle. See [Build a plant](../how_to/build_a_plant.md) and
[Parameterize a model from data](../how_to/parameterize_from_data.md) for
the API those examples build on.
